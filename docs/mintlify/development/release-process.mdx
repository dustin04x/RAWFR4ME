## Release process

## 1.0.0 release

The first stable release of RAWFRAME. Milestones 1–10 are complete and covered
by the workspace test suite. Milestone 11 (passive analysis) ships as a library
only with no Findings UI.

### Release assets

- Linux x86_64 binary built from tagged source with `--locked`.
- SHA-256 checksums published alongside the release.
- Release notes with version, tag SHAs, and gate results.
