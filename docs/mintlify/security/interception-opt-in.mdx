## Interception opt-in

TLS interception is opt-in and requires explicit configuration. It is not enabled by
default.

## Enabling interception

Start RAWFRAME with the `--intercept` flag:

```bash
cargo run -p rawframe-cli --bin rawframe -- --intercept
```

## Local CA trust

Interception requires a trusted local CA. After enabling interception:

1. Export the local CA certificate from RAWFRAME's data directory.
2. Install the CA certificate into the system trust store or browser.
3. For browsers: go to settings → certificates → authorities → import.
4. For system trust (Linux): `cp rawframe-ca.pem /usr/local/share/ca-certificates/` and
   run `update-ca-certificates`.

## Limitations

- Pinned clients fail the intercepted handshake by design. RAWFRAME does not
  bypass certificate pinning.
- Modified HTTPS requests cannot change the original `CONNECT` authority.
- No URL, headers, body, or tunnelled certificate is visible in opaque tunnels.
