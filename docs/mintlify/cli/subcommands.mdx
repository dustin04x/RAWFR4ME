## Subcommands

RAWFRAME CLI does not have subcommands in the traditional sense. All configuration
and action is performed through flags and arguments passed to the `rawframe`
binary.

## Primary command

```bash
rawframe [FLAGS]
```

The binary enters the TUI (terminal user interface) upon startup. No subcommands
like `serve`, `proxy`, or `analyze` are supported; all behavior is controlled
through flags and keybindings within the TUI.
