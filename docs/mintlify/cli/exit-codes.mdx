## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success — the command completed normally. |
| `1` | General error — an unexpected failure occurred. |
| `2` | Validation error — a CLI argument or configuration value was invalid. |
| `3` | Database error — persistence could not be initialized or maintained. |
| `4` | TLS error — a TLS handshake or certificate error occurred. |
| `5` | Scope error — the destination does not match any allowlist rule. |
