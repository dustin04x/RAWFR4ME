## Keyboard shortcuts

## TUI shortcuts (workspace)

| Shortcut | Action |
| --- | --- |
| `Ctrl+K` | Open the command palette. |
| `Ctrl+1` | Switch to Proxy workspace. |
| `Ctrl+2` | Switch to HTTP History workspace. |
| `Ctrl+3` | Switch to Repeater workspace. |
| `Ctrl+4` | Switch to Settings workspace. |
| `Ctrl+5` | Switch to Intruder workspace. |
| `Ctrl+6` | Switch to Decoder workspace. |
| `Ctrl+7` | Switch to WebSocket workspace. |
| `Ctrl+F` | Search HTTP History. |
| `Ctrl+N` | Create a new Repeater tab. |
| `Ctrl+W` | Close the current Repeater tab. |
| `Ctrl+U` | Clear HTTP History filters. |
| `Ctrl+C` | Immediate emergency exit. |
| `Q` | Quit; confirmation required with unsaved edits or paused requests. |
| `P` | Toggle the proxy (only when not editing). |
| `I` | Enable/disable interception (only when not editing). |
| `B` | Browse stored sessions (restore read-only, export). |
| `Tab` / `Shift+Tab` | Move focus between navigation, content, and inspector. |
| `?` | Show keyboard help. |

## Per-workspace shortcuts

Per-workspace shortcuts are listed in the `?` help overlay and in
[docs/development.md](docs/development.md).
