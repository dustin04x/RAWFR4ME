## Keyboard shortcuts

## Global shortcuts

| Key | Action |
| --- | --- |
| `P` | Open/close proxy screen |
| `R` | Open repeater workspace |
| `I` | Open intruder workspace |
| `D` | Open decoder workspace |
| `H` | Open history/inspector workspace |
| `S` | Open settings |
| `F` | Focus search field |
| `C` | Open command palette |
| `Esc` | Close modals and return to normal mode |
| `Q` | Quit application |

## Proxy screen shortcuts

| Key | Action |
| --- | --- |
| `S` | Start/stop proxy listener |
| `A` | Add scope allowlist entry |
| `D` | Remove scope allowlist entry |
| `P` | (toggle) Pause/resume capture |

## Intruder screen shortcuts

| Key | Action |
| --- | --- |
| `C` | Add/configure position |
| `R` | Run/stop attack |
| `P` | Pause/resume |
| `S` | Send selected results to Repeater |

## Decoder screen shortcuts

| Key | Action |
| --- | --- |
| `T` | Transform selection |
| `R` | Transfer to Repeater |
| `Esc` | Cancel and return |

## Navigation shortcuts

| Key | Action |
| --- | --- |
| `Tab` | Move focus forward |
| `Shift+Tab` | Move focus backward |
| `Enter` | Activate selected item |
| `Up/Down` | Navigate lists |
| `Left/Right` | Navigate panels |
