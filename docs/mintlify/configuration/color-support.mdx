## Color support

RAWFRAME uses a restrained color palette with deep graphite and near-black surfaces,
and violet as the primary accent.

## Theme colors

- **Light**: `#A78BFA` (light violet)
- **Dark**: `#6D28D9` (dark violet)
- **Primary**: `#8B5CF6` (violet accent)

## Semantic colors

- **Green** = success
- **Amber** = warning
- **Red** = error/destructive
- **Muted gray** = metadata

## Terminal color support

- **Truecolor** (24-bit RGB) — assumed and recommended.
- **8/16-colour ANSI terminals** — palette-based rendering; colors may differ
  from the intended theme.
- The application assumes a monospace font with box-drawing glyph coverage.
